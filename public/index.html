How this works

How to review a page

Start with an audience page and read it as a first-time visitor. Choose “Find my music,” then fill in the sample birth details to try the example signup.

When giving feedback, include the audience, version number, and the section you're commenting on. That keeps everyone talking about the same page.

What do the statuses mean?

Michael reviews the drafts. Walter publishes approved pages to the customer website.

What is still being tested?

These previews show the copy, layout, and an example path from birth details to plan choice. The example results aren't calculated from your entry. Audio doesn't play, and these pages don't create accounts, start paid memberships, or send marketing events.

Mobile appearance, keyboard and screen-reader access, image loading, and speed still need checking.

This hub lists working previews. Customer publication is tracked separately with the Live status and a customer-site link.

For people maintaining this list

Page names, descriptions, example partners, and statuses live in pages.json. Newest available versions are selected automatically within each page family. A newer version doesn't change its approval status.
